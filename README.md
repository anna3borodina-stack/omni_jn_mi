[Uploading READ# Курс: статические HTML-проекты

Учебная папка с одностраничными приложениями и вёрсткой. Всё работает без сборки и сервера: достаточно открыть HTML в браузере.

## Быстрый старт

1. Клонируйте репозиторий или скачайте архив папки.
2. Откройте в браузере файл **`index.html`** — приветственный лендинг и ссылки на инструменты.
3. Основное приложение: **`калькулятор2.HTML`** — калькулятор семейного бюджета (localStorage, экспорт/импорт JSON, тёмная тема).

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Главная: короткий лендинг и навигация |
| `калькулятор2.HTML` | Калькулятор доходов и расходов |
| `помошник*.HTML`, `Помошник маркетплейсер*.HTML` | Варианты помощника для маркетплейсов |
| `сайт*.HTML`, `свйт 3.HTML`, `сайт NEWGOLD*.HTML` | Учебные макеты сайтов |
| `gjcktlybq.HTML` | Дополнительная страница курса |

## Публикация в сеть

Загрузите всю папку на любой **статический** хостинг (GitHub Pages, Netlify, Vercel static и т.п.). Убедитесь, что точка входа — `index.html`, а имена файлов с кириллицей поддерживаются вашим хостингом (обычно да).
